Attention
• 예를 들어, "The cat sat on the mat"라는 문장에서 Self-Attention은 "cat"이
  "sat"와 강하게 관련되어 있음을 학습.
• 이렇게 단어들 간의 관계를 학습함으로써 모델은 문맥을 이해할 수 있으며, 이는
  특히 문장 구조가 복잡하거나 장기적인 의존성을 다룰 때 매우 유리
• Self-Attention 메커니즘은 순차적인 처리를 요구하지 않기 때문에 모든 단어에
  대해 병렬로 상관관계를 계산
• Self-Attention 메커니즘을 통해 단어들 간의 상관관계를 학습한 후, 그 결과를
  Dense Layer로 전달하는 방식은 트랜스포머 모델의 성능을 크게 향상
• Multi-Head 이므로 N개의 K, Q, V 임계치 배열이 만들어지고, 서로 다른
  상관관계를 학습 ( CNN에서 여러 개의 Kernel을 도입하는 개념과 비슷 )
• Dense Layer는 비선형성을 도입하여 Self-Attention에서 학습된 상관관계 정보를
  더욱 풍부하고 복잡한 특징으로 변환

Feed Forward
• 트랜스포머 모델의 Feed Forward 층은 Self-Attention 층의 출력을 비선형적으로
  변환하여 모델의 표현력을 강화
• 이 층을 통해 모델은 단순한 상관관계 이상의 복잡한 패턴을 학습할 수 있으며,
  각 위치에서 독립적으로 계산이 이루어져 병렬 처리의 장점도 살릴 수 있다.

Add
• Add 단계에서의 Residual Connection 개념을 사용
• 트랜스포머 모델의 각 인코더 및 디코더 블록에서, Self-Attention 층이나 Feed
  Forward 층을 통과한 출력에 Residual Connection을 사용하여 원래의 입력을
  더합니다.
• 수식으로 표현하면: Output=Layer Output + Layer Input
  ➢   Layer Output은 Self-Attention이나 Feed Forward 층을 통과한 출력
  ➢   Layer Input은 그 층에 주어진 원래의 입력입니다.

• 딥러닝 모델이 깊어질수록, 즉 층이 많아질수록 역전파 과정에서
  기울기(gradient)가 소실되는 문제가 발생할 수 있습니다.
• Residual Connection은 이 문제를 완화하여 더 깊은 네트워크를 안정적으로
  학습할 수 있게 합니다.원래의 입력 값을 출력에 더해줌으로써, 역전파 시
  기울기가 안정적으로 전파될 수 있습니다.
